# 🚗 Smart Shape-Based Object Counter & Analyzer

نظام كامل وذكي لكشف وعد السيارات والدراجات من الفيديوهات باستخدام تقنيات معالجة الصور المتقدمة.

## 🎯 المميزات

✅ **كشف السيارات والدراجات** - اكتشاف فوري وذكي  
✅ **تحليل الأشكال** - استخدام Hough Transform للدوائر والخطوط  
✅ **عداد ذكي** - تجنب عد الكائن مرتين  
✅ **Trackbars تفاعلية** - تحكم فوري بالمعاملات  
✅ **معالجة صور متقدمة** - Canny, Gaussian Blur, وغيرها  
✅ **واجهة سهلة** - عرض واضح للنتائج  

## 📋 المتطلبات

- Python 3.7+
- OpenCV 4.8+
- NumPy 1.24+

## 🚀 التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone https://github.com/momohisham1331-oss/Smart-Shape-Based-Object-Counter.git
cd Smart-Shape-Based-Object-Counter
```

### 2. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 3. تشغيل البرنامج
```bash
python main.py your_video.mp4
```

**مثال:**
```bash
python main.py cars.mp4
python main.py bicycles.mp4
```

## 🎛️ Trackbars (المنزلقات)

| الاسم | الوصف | النطاق |
|------|-------|--------|
| **Canny Low** | الحد الأدنى لكشف الحواف | 0-300 |
| **Canny High** | الحد الأقصى لكشف الحواف | 0-300 |
| **Hough Threshold** | حساسية كشف الخطوط | 0-200 |
| **Circles Param2** | حساسية كشف الدوائر | 0-100 |

## 📊 كيفية عمل البرنامج

### 1. **معالجة الصورة**
- تحويل إلى رمادي (Grayscale)
- تطبيق Gaussian Blur للتقليل من الضوضاء

### 2. **كشف الحواف**
- استخدام Canny Edge Detection
- كشف حدود الكائنات

### 3. **البحث عن الأشكال**
- **Hough Transform** للدوائر (العجل)
- **Hough Transform** للخطوط (أجزاء السيارة)

### 4. **تصنيف الكائنات**
- سيارة: إذا كان لديها 2+ دوائر و 2+ خطوط
- دراجة: إذا كان لديها 2 دوائر
- غير معروف: باقي الحالات

### 5. **التتبع والعد**
- تتبع موضع كل كائن
- تجنب عد الكائن الواحد مرتين
- عداد منفصل للسيارات والدراجات

## 🐛 استكشاف الأخطاء

### الفيديو لا يفتح؟
- تحقق من امتداد الفيديو (mp4, avi, mov, إلخ)
- استخدم المسار الكامل للفيديو

### لا يتم كشف الكائنات؟
- اضبط **Canny Low** و **Canny High**
- قلل **Hough Threshold** لزيادة الحساسية
- تأكد من وضوح الفيديو

### الأداء بطيء؟
- استخدم فيديو بدقة أقل
- أغلق البرامج الأخرى
